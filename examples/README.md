# KTAPEOUT 0.5.0 Examples

These small JSON fixtures demonstrate deterministic source, composition and
Profile-invariant inputs for local inspection. They are unsigned teaching
examples and are not L1 evidence, signer authority, fee estimates or Mainnet
claims.

The examples are compatible with the 0.5.0 Core and CLI candidate under
`../core/`. Use the documented `ktape` commands to inspect or validate them;
do not treat fixture data as a wallet or deployment credential. The short IDs
in these teaching fixtures are generic Profile identifiers; they are not
claims of canonical registry ownership. New registry objects must follow the
[naming reference](../docs/reference/naming.md).
