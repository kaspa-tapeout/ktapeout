# Protocol specification map

Status: **NORMATIVE — SOLE ENGLISH SPECIFICATION**  
The English specification in `spec/KTAPEOUT_0.5.0_NORMATIVE_SPEC.md`, together
with the 0.5.0 IDL, schemas and canonical vectors in `spec/`, is authoritative.

This page is the English developer map for the normative specification. It is
explanatory and cannot amend the specification.

The 0.5.0 specification covers:

- bounded Core objects and canonical encoding;
- Profile, artifact, application and state commitments;
- resource, network and execution policy boundaries;
- composition, locks, dependencies and deterministic identity;
- evidence labels, readback and fail-closed behavior;
- external signer/provider and L1 adapter boundaries.

The repository includes the [normative English specification](../../spec/KTAPEOUT_0.5.0_NORMATIVE_SPEC.md),
the [machine-readable contracts](../../spec/README.md), and a
[requirements crosswalk](../../spec/requirements-crosswalk.md). The crosswalk
is explanatory; the specification remains authoritative when an explanatory
document differs.

The key words **MUST**, **MUST NOT**, **REQUIRED**, **SHALL**, **SHALL NOT**,
**SHOULD**, **SHOULD NOT**, **RECOMMENDED**, **NOT RECOMMENDED**, **MAY**, and
**OPTIONAL** are interpreted as described in BCP 14 [RFC2119] [RFC8174] when,
and only when, they appear in all capitals.
